# 牙科诊所管理系统分析与设计报告

版本日期：2026年10月16日。作者：陈杨娟，学号：1602240104。

本套材料包含业务建模、需求、分析、数据库与实现设计四部分。Word、Markdown及PDF使用同一份报告正文、表格和图形；PDF共100页，关系数据库图位于最后7页，采用A3横向页面。

- Word：用于阅读、修订和打印。
- PDF：用于固定版式阅读及打印；最后7页可选择A3横向纸张。
- Markdown：用于文本检索与继续编辑，需与assets目录保持相对位置。
- 图形源文件/牙科诊所关系数据库图.vsdx：Visio原生可编辑图源，共7页，包括关系总览及6个业务分区。
- assets/erd-0.svg至erd-6.svg：关系图矢量文件，便于单独放大查看；assets目录同时保存报告其余配图。

数据字典列出32个领域模型及3张实际多对多连接表，共35张表、302个字段。auth_permission与auth_group仅在关系图中作为框架主键引用节点。
