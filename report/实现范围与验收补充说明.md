# 实现范围与验收补充说明

作者陈杨娟，学号 1602240104。本说明与[分析与设计报告](1602240104陈杨娟-牙科诊所管理系统.pdf)一并提交，补充报告编制后的系统实现、数据字典与验收结果。

| 功能 | 当前实现 |
| --- | --- |
| 过敏确认 | 预约和接诊分别核实并记录。历史空记录显示未核实。 |
| 工作日历 | 支持休诊、临时停诊和调休。保留既有预约，可从停诊协调页核对影响。 |
| 耗材成本 | 按采购批次、就诊、接诊医生和诊所归集。退回冲销原领用季度，公共费用单列。 |
| 前台当天日程 | 按日期、门店和医生筛选，可查看预约、可约时段、休诊和资源停用。 |
| 停诊跨店改约 | 核对两店权限、患者同意、资质、转场、排班、资源和周转。同一时段发生竞争时，未成功的一方保留原预约。 |
| 患者诊疗时间线 | 按患者档案串联预约计划、进度和已完成治疗，按岗位和门店授权展示。 |

报告数据字典记载 38 个已实现领域模型。迁移 0007 新增以下两项，仓库源码共实现 40 个领域模型。

| 新增模型 | 字段及约束 |
| --- | --- |
| 门店转场时间（ClinicTransferTime） | UUID 主键。出发诊所与到达诊所为外键，方向唯一且两店不同。最短转场时间为 1 至 720 分钟，可启用或停用。 |
| 跨店项目所需资质（TreatmentQualificationRequirement） | UUID 主键。治疗项目与资质为外键，治疗项目留空表示咨询，组合唯一。一个项目有多项启用要求时须全部满足。 |

本机专用 PostgreSQL 测试库 119 项回归通过。10 万条虚构预约、20 路请求持续 120 秒的本机混合压测中，3,360 次请求均成功。可约时段 P90/P95 为 0.352/0.385 秒，预约提交为 0.527/0.585 秒。测量条件为同机环回网络及虚构数据。

本机初始化数据覆盖案例中的 15 家门店。案例未列出具体门店名称或地址，报告附录「课程验收样例资料」汇总了本机使用的虚构名称和地址。地址用于展示预约流程，请勿据此前往就诊。

教师网页保留 11 月 21 日的业务功能，已于 11 月 26 日优化界面文案和部分样例资料。公网展示预约、就诊和模拟结算。当前网页及微信扫码入口的使用步骤见[在线验收操作说明](在线验收操作说明.md)，完整本机流程见仓库首页。
