# 牙科诊所管理系统

作者：陈杨娟　学号：1602240104　班级：信管2401

本项目以ADC课程案例为设计对象；岳雅口腔医院为实地调研样本，两者分别说明。运行数据为虚构演示，不代表调研门店。

本项目使用Django与PostgreSQL，支持患者档案、医生排班、预约、签到、就诊记录、受控更正、结算单、模拟收款、成本和经营统计。患者、前台、医生、诊所管理者、总部、财务和系统管理员分别按授权范围操作。

## 运行

Python环境安装requirements.txt中的依赖，数据库使用PostgreSQL并允许创建btree_gist扩展。Windows本地文件、虚拟环境、缓存与数据库应保存在D盘。数据库密码、DJANGO_SECRET_KEY等通过进程环境配置，配置项目见.env.example；该文件不含实际秘密且不会自动加载。

从仓库根目录设置DJANGO_SETTINGS_MODULE=config.settings_cloud、DATABASE_URL和独立随机DJANGO_SECRET_KEY。云端设定实际域名、HTTPS与代理配置；仅本机验证时可设置DJANGO_ALLOWED_HOSTS=127.0.0.1,localhost,testserver、DJANGO_HTTPS=0，DB_SSLMODE根据本机数据库实际配置选择。

初始化数据库和静态资源：

```text
python scripts/cloud_prepare.py
```

Linux云端使用Gunicorn：

```text
python scripts/cloud_start.py
```

Windows本机使用开发服务器：

```text
python app/manage.py runserver 127.0.0.1:8000
```

首次演示初始化需设置INITIALIZE_DEMO=1及DEMO_INITIAL_PASSWORD。只允许空库初始化；已有演示数据时不重建、不修改密码。后续设INITIALIZE_DEMO=0。所有演示患者与经营数据均为虚构，模拟收款不发生真实交易。

## 当前实现范围

支持一个或多个连续30分钟排班单元、治疗预计时长与清洁周转、牙椅及设备与辅助人员容量、部分资源停用、原子改约和取消、治疗延长协调、误签到和爽约纠错。手机号用于检索与重复提示；本人核验、账号关联与手机号变更保存审计记录。

辅助人员采用诊所容量池，未实现具体护士的跨店个人排班。团购外部核销接口、真实支付、退款和医学影像不属于当前演示功能。现有测试结果不代表报告中的性能目标已达标。

界面采用门店编号、牙齿线稿标识、角色信息、日期牌及预约时间与资源卡片。日期、营业时段和待办数量读取实际数据，不使用固定展示数字。

英文辅助提供252条本地界面译文，覆盖登录、注册密码要求、导航、核心标题、表单标签与提示、状态选项、报表列及统计边界。默认显示中文，开启后增加英文提示，并在同一浏览器会话的页面跳转中保留设置。患者姓名、临床自由文本及动态档案选择项保留原文；未知提示及部分非核心业务说明仍保持中文，不作为完整英文版系统。

界面采用暂定C版的深绿与陶土配色、衬线标题、系统正文字体、弧形照片、按钮及辅助开关；前台首页与导航采用“前台接诊台”。照片来源见界面素材来源.md，非调研门店实拍。工作台日期、营业时段和人数读取当前授权数据，不使用样稿中的固定人数。普通显示、窄屏以及大字与英文辅助组合均已复核，独立样稿不纳入提交包。

C版与语言辅助接入后71项完整回归通过；页面修正后，对各角色页面、CSRF、导航上下文、跨店隔离及预约核对的6项既有测试再次通过（包含注册事务）。6项属于复跑，不增加测试总数。
